# English.tools: сохранение и первый выпуск — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Работа ограничена English.tools; план не разрешает дополнительные установки, расходы или публикацию без необходимого согласования.

**Goal:** Сохранить существующий фронтенд в публичном GitHub и подготовить его к первому размещению без нового редизайна.

**Architecture:** Рабочая папка проекта — `site`; готовый интерфейс находится в `dist`. Единая база `content/catalog.json` формирует каталог и поиск; кабинеты пока сохраняют данные локально. Публичный выпуск статического сайта и серверная реализация кабинетов разделены.

**Tech Stack:** HTML, CSS, JavaScript, Python 3.10+, Node.js 20+, Git.

**Spec:** [prd.md](../../../prd.md).

## Global Constraints

- Публичный сайт работает без входа и оплаты.
- Согласованные главная, логотип и стиль сохраняются.
- Репозиторий проекта в GitHub должен быть публичным.
- Кабинеты не являются платной частью каталога.
- Каталог имеет единственную рабочую базу `content/catalog.json`.
- Подготовка репозитория не меняет файлы интерфейса в `dist`.
- Регистрацию, пароль, подтверждение почты и принятие условий GitHub завершает владелец.

## Review Focus

- После скачивания проекта отсутствуют соседние рабочие папки: запуск, сборка и проверки используют только файлы репозитория.
- Повторное раскрытие и сворачивание списка: существующая проверка каталога подтверждает исходные шесть карточек и отсутствие потерь поиска.
- Копия попадает на публичную площадку: архивы, секреты и файлы синхронизированного проекта исключены из набора.
- Кабинет сохраняет локальный ответ: интерфейс и документация не обещают отправку преподавателю.
- Сайт размещён в подпапке: абсолютные ссылки потребуют настройки; первый выпуск размещается в корне домена.

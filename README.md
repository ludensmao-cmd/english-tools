# English.tools

Русскоязычный сайт с инструментами для английского, блогом и конструктором первого урока с ИИ. Публичная часть доступна без входа. Кабинеты ученика и преподавателя работают через отдельные учётные записи и общую локальную базу.

Сохранённый состав на 7 октября 2026 года: **611 ресурсов, 11 страниц каталога, 25 словарей, 4 статьи**. Согласованные главная, прозрачный логотип и тёмные цвета Lobby сохранены.

## Запуск

Для публичного сайта нужны Python 3.10+ и Node.js 20+. Кабинеты проверены на установленном Node.js **26.8.1** со встроенным `node:sqlite`; требование Node.js 20+ относится к публичным проверкам, а не к серверу кабинетов. Дополнительные npm-пакеты не нужны; `npm install` выполнять не требуется.

Из папки проекта:

```sh
npm start
```

Откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Терминал с сервером должен оставаться открытым; остановка — Ctrl+C.

Можно запустить напрямую, без npm:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Для фонового просмотра на Mac предусмотрена команда `npm run preview`. Она проверяет уже запущенную главную и при необходимости создаёт отдельный процесс с абсолютным путём к `dist`. Журнал и данные процесса находятся в `/private/tmp/english-tools-preview-4173.*`; автозапуск при включении компьютера не настраивается. Если порт 4173 занят другим проектом, сначала остановите тот сервер или выберите свободный порт для обычного запуска.

Для рабочих кабинетов сначала создайте преподавателя по [инструкции](docs/classroom-setup.md), затем запустите:

```sh
npm run classroom
```

Вход: [http://127.0.0.1:4174/lessons/login.html](http://127.0.0.1:4174/lessons/login.html). Сервер на 4174 также отдаёт весь публичный сайт. Обычный статический просмотр на 4173 не обслуживает учебные данные.

## Как обновлять каталог

Единственная рабочая база — `content/catalog.json`. Ресурс содержит уникальный `id`, название, URL, описание, направления, ограничения, `catalogGroup` и тематические `placements`. Новый ресурс должен попадать как минимум в одну категорию кроме стартовой подборки.

Меняйте эту базу, затем выполните:

```sh
npm run build
npm run check
```

Сборка обновляет страницы каталога, поисковый индекс, совместимый экспорт и оболочку категорий. Главная, блог, ИИ и кабинеты этой командой не пересобираются. Сборка работает без интернета и установленных npm-зависимостей. Отчёт записывается в игнорируемый `research/catalogue-build-2026-10-07.json`.

Поиск охватывает все карточки, включая скрытые, и поддерживает русские названия. Параметры `q` и `skill` сохраняются в адресе. В каждой группе сначала видно до шести карточек; «Показать ещё» раскрывает следующую порцию, «Свернуть» возвращает исходную. Карточки ведут напрямую на сторонний сайт.

Подкасты идут в порядке: 21 на собственных сайтах и Podbean, 13 на YouTube, 21 на Spotify. Каждый действующий ресурс присутствует в общем списке и хотя бы одной тематической категории. Меню словарей и поиск строятся из той же базы.

`scripts/build_home.py`, импорт и исторические сборщики не используются для обычного обновления каталога. Не запускайте их для восстановления главной: утверждённая версия уже сохранена в `dist`.

## ИИ, Telegram и кабинеты

Конструктор ИИ собирает цель и уровень, формат и приложение, тему и время. Результат — занятие и текст запроса для внешнего ИИ. Встроенная модель, платный API, проверка ответов и дневной лимит не подключены. Библиотека запросов и отдельные сценарии письма отсутствуют в интерфейсе; архив прежних инструкций сохранён в данных.

Настоящий Telegram ещё не указан. В `dist/site-config.js` поле `telegramUrl` пустое; кнопки ведут на внутреннюю страницу с объяснением. Для подключения нужно подставить предоставленный владельцем HTTPS-адрес `t.me` или `telegram.me`.

Преподаватель создаёт ученика с временным паролем, назначает занятия и домашние задания с файлами, завершает урок саммари, словарём и материалами, проверяет ответы. Ученик меняет временный пароль, получает свои задания, отправляет текст и файлы и читает отзыв. Три окна повторения сохранены. Роль определяется сервером; изменение адреса не открывает чужой кабинет.

Данные хранятся в SQLite и приватной папке загрузок. Сохранённые ответы, задания, отзывы и файлы доступны после нового входа и перезапуска. Несохранённый черновик остаётся в открытой вкладке, в том числе при окончании сессии; после нового входа отправку нужно подтвердить вручную. Закрытие или перезагрузка вкладки не сохраняет черновик. Прежние демонстрационные данные IndexedDB не удаляются и автоматически не переносятся.

Это рабочая локальная версия. Домен и HTTPS-размещение для доступа с других устройств ещё не подключены. Ограничения: 20 МБ на файл, 10 файлов и 50 МБ на задание или ответ. Остаток занятий задаётся вручную. Самостоятельной регистрации, Telegram-бота, MCP и автоматического списания уроков нет.

## Состав репозитория

- `dist/` — готовый сайт, локальные шрифты, логотипы и изображения.
- `content/` — единая база ресурсов.
- `templates/catalog/` — макеты категорий для сборки.
- `scripts/` — запуск, сборка и проверки; исторические утилиты сохранены отдельно по назначению.
- `server/classroom/`, `tests/classroom/` — учебный сервер, база, права, файлы, резервные копии и изолированные проверки.
- `var/classroom/`, `backups/classroom/` — приватные данные и копии; полностью исключены из Git, не входят в `dist`.
- `design/`, `DESIGN.md` — согласованные дизайн-договорённости.
- `prd.md`, `docs/superpowers/plans/` — требования и этапы.
- `test-fixtures/` — неизменные данные, необходимые для проверки прежних удалений и экспорта.
- Явно разрешённые файлы `research/` — публичные исходные снимки и отчёты, необходимые текущей сборке и проверкам. Остальные исследования, снимки экрана и архивы игнорируются Git.

## Проверки

```sh
npm run check
```

Проверка исходников охватывает 29 HTML-файлов, локальные ссылки и якоря, ID, подписи полей, JSON-LD, синтаксис JavaScript и логотип. Проверка каталога подтверждает полноту 611 ресурсов, совпадение категорий и поиска, отсутствие турецких записей и раздела соцсетей, порядок подкастов, поиск, фильтры, раскрытие и сворачивание списков.

`npm run check:classroom` проверяет учебный сервер на отдельных временных базах: вход, смену/сброс пароля, права, повторную отправку, файлы, обмен заданием/ответом/отзывом, перезапуск и восстановление копии. В браузере проверены обе роли, три окна повторения и Escape, сохранение текста и выбора файла при окончании сессии, повторный вход и ручная отправка, отзыв преподавателя, ширины 390 и 1440 px без горизонтального переполнения. Реальные ученики не созданы автоматически. Эти проверки не подтверждают доступность всех внешних сайтов.

## Размещение и текущее состояние

Публично размещается только `dist`. Сайт использует абсолютные пути от корня (`/links/...`), поэтому первая площадка должна отдавать его из корня домена. Обычная GitHub Pages-подпапка вида `/english-tools/` потребует адаптации путей; наличие репозитория само по себе сайт не размещает.

Домен, HTTPS-площадка и платежи пока не подключены. Для публичной части достаточно статического размещения; кабинетам нужен Node.js-сервер с постоянным диском и отдельно настроенными HTTPS и резервным копированием. Авторизация и общие учебные данные уже работают локально. Новых обещаний о платном клубе и реферальных продажах школ в проект не добавляем.

7 октября 2026 года проект сохранён в публичном GitHub. Первый коммит — `87f761e1b7c23d546cad1ea2e73052785e68b083`, 521 файл. Отдельно скачанная копия совпала с локальной по SHA256 каждого файла и прошла `npm run check`. Публикация репозитория не включает размещение сайта, платежи или серверные кабинеты.
